# HyperAI TUI 键位表

> 状态：与实现同步（`apps/tui/src/view.ts` 的键位路由为准）。标 P3 的是计划中未实现项；范围见 [development-plan.md](development-plan.md)。

## 全局 / 输入区

| 键 | 动作 | 状态 |
|---|---|---|
| `Enter` | 发送任务（弹层中为确认/提交答案） | ✅ |
| `Ctrl+J` | steer 打断进当前回合 | ✅ |
| `Esc` | 运行中：取消回合；空闲：清空输入；弹层：关闭/跳过 | ✅ |
| `Ctrl+C` | 运行中：取消回合；空闲：退出 TUI | ✅ |
| `Shift+Tab` | 循环权限预设（无预设服务时 ask ⇄ never） | ✅ |
| `Ctrl+Enter` | 打断当前回合并发送 | ✅ |
| `Alt+Up` | 历史回溯 | ✅ |
| `↑` / `↓` | 输入历史回溯 | ✅ |
| `PgUp` / `PgDn` | 滚动会话（下一次输出重新贴底） | ✅ |
| `Shift+Enter` | 换行（多行草稿） | P4 |
| `Ctrl+U` / `Ctrl+W` | 清空输入 / 删词 | ✅ |
| `Ctrl+T` / `Ctrl+X` | 思考展开 / 工具卡展开 | P4 |

## 命令（输入 `/` 开头）

| 命令 | 动作 | 状态 |
|---|---|---|
| `/help` | 帮助覆盖层（命令 + 键位） | ✅ |
| `/tools` | 浏览本会话工具卡 | ✅ |
| `/model` | 模型路由与力度信息 | ✅ |
| `/clear` | 清空转录视图 | ✅ |
| `/settings` | 语言与通知设置 | ✅ |
| `/exit` `/quit` | 退出 TUI | ✅ |
| `/resume` | 会话列表选择并恢复 | ✅ |
| `/new` | 新会话 | ✅ |
| `/effort` | 推理力度循环 | ✅ |

## 审批弹层（工具升级请求时）

| 键 | 动作 | 状态 |
|---|---|---|
| `↑` / `↓` | 在选项间移动 | ✅ |
| `a` | 允许一次（allowed-once） | ✅ |
| `r` | 拒绝（rejected） | ✅ |
| `Enter` | 确认当前选项 | ✅ |
| `Esc` / `q` | 取消（cancelled） | ✅ |

## 提问弹层（ask_user_question）

| 键 | 动作 | 状态 |
|---|---|---|
| `↑` / `↓` | 问题间移动 | ✅ |
| `Space` | 切换选中（多选可选多项） | ✅ |
| `i` | 进入自定义文本（在输入框打字，Enter 提交，Esc 返回） | ✅ |
| `Enter` | 提交答案批次 | ✅ |
| `Esc` | 跳过全部问题 | ✅ |

## 其他覆盖层（/help /tools /model）

| 键 | 动作 | 状态 |
|---|---|---|
| `Esc` / `q` | 关闭 | ✅ |
